Robot code for the 2026 season from [Griffitrons 1661](https://team1661.com), the FIRST Robotics Competition team at The Buckley School.

Unlike earlier years, this one is written in **Python** with [RobotPy](https://robotpy.readthedocs.io/)
and the command-based framework (`robotpy-commands-v2`).

## ✨ Features

- **Swerve drivetrain** built on CTRE Phoenix 6, with constants generated by Tuner X
  (`generated/tuner_constants.py`) and wrapped in `subsystems/command_swerve_drivetrain.py`
- **Shooter** subsystem (`subsystems/shooter.py`): flywheel, feeder and screw motors on TalonFX controllers
  with current limits and velocity control
- **PathPlanner autonomous** routines (`deploy/pathplanner`) with named commands for the shooter,
  feeder, intake and more
- Field-centric driving with Xbox controller / joystick bindings and SysId routines in `robotcontainer.py`
- Drivetrain telemetry published to NetworkTables (`telemetry.py`)
- `pyfrc` tests in `tests/`

## 🗂️ Layout

| Path | What it is |
| --- | --- |
| `robot.py` | Robot entry point (`commands2.TimedCommandRobot`) |
| `robotcontainer.py` | Subsystems, button bindings and autonomous setup |
| `subsystems/` | Drivetrain and shooter subsystems |
| `generated/` | Tuner X generated swerve constants |
| `deploy/` | Files copied to the roboRIO (PathPlanner paths and autos) |
| `tests/` | `pyfrc` tests |

## 🛠️ Building and running

Install [RobotPy](https://robotpy.readthedocs.io/en/stable/install/robot.html) on your computer, then:

```bash
python -m robotpy sync     # download the robot's dependencies (see pyproject.toml)
python -m robotpy sim      # run in the simulator
python -m robotpy test     # run the pyfrc tests
python -m robotpy deploy   # deploy to a roboRIO (must be connected to the robot)
```
